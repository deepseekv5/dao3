在本地跑一套 dao3.fun 的编辑器、运行时和建模器

全部代码是这个仓库自己写的。参照的是官方公开的东西：box3-product-document 文档、GameAPI.d.ts 类型声明、docs.dao3.fun，以及官方开源的方块图集仓库。目标是读得懂官方导出的地图、跑得动官方写法的脚本，不是复刻源码，也拿不到源码。

用途很具体：拆开学引擎的分层怎么做、把玩法脚本丢进去看它到底怎么跑、离线搭图不依赖网络。数据全在你这台机器上。

怎么做的

渲染

three.js r160。区块按 16³ 合批，分成不透明、透明、自发光、空气墙四个网格桶。方块接缝和序列帧动画都由 onBeforeCompile 注进去的 shader 驱动，播放和切换都不会触发重编译。

数据

构建期脚本把官方方块 ID 表、渲染规则和 16×16 贴图合成一张图集，顺带算出每个方块的碰撞、质量、摩擦、速度、流体和动画帧。地图以 gzip JSON 存在 server/data/worlds/。

运行时

固定步长累加器驱动 tick，物理、区域、环境、定时器、脚本回调分段跑，每段各自捕获异常——一个子系统炸了不会把整个循环带走。实体接触检测用 AABB 扫描剪枝，官方那张图 199 个实体同时在里面也不卡。

怎么算验证过

不看编译过不过。用浏览器驱动真实页面，读像素和状态数值：按住 W 一秒走了多远、抽屉在启动时是不是 display:none、关掉模型层之后画面像素和差多少。编译通过但面板宽度是 0，不算做完。

跑起来

要 Node 18 以上。一条命令：首次会自动构建方块图集，然后清掉本项目遗留的旧实例、挑一个空闲端口起服务。

./run.sh

首页可以直接创建地图，也能把示例的「赛车模板」复制一份出来改，原件不动。别的项目占了默认端口就顺延，不会去杀别人的进程。

PORT=8080 ./run.sh                          # 指定端口
node scripts/build-block-atlas.mjs          # 改了贴图或 spec 之后重建图集
node scripts/import-official-project.mjs    # 从仓库内的官方数据重建示例地图
node scripts/fetch-official-audio.mjs       # 补齐 40 个官方音效
