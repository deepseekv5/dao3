造一张图，发出去，别人点开就能玩

老攸元宇宙把三件平时分属不同公司的事接到一起：造（体素编辑器 + VOXA 建模 + 玩法脚本）、发（一键发布成不可变快照，别人点开就能跑）、处（账号、好友、关注、评论、点赞、通知）。参考的是 Roblox 那套"内容全部由玩家产出"的闭环，以及 dao3.fun 把 AI 接进创作流程的思路。

区别在于它跑在你自己的机器上：一条 ./run.sh 起服务，账号、地图、评论全落在本机磁盘，没有远端服务器，也没有把你的作品上传到谁的平台上。

五根支柱

宣传图上写着"AI 时代赋能元宇宙"。这里把每一根支柱实际做到哪一步摊开写，做没做的都标出来。

支柱现在能用的部分还没做
AI 智能创作编辑器里接了 OpenAI 兼容接口：AI 写玩法脚本、AI 生成体素模型、报错回喂、语法预检；模型与密钥你自己填一键生成整张地图
开放世界体素地形 + 模型实体 + 区域触发 + 昼夜与天气 + 第三人称/驾驶相机，脚本能改世界状态跨图连成同一个大世界
社交互动账号、关注、好友、评论、点赞、通知、广场排序与搜索；同图实时联机与内置聊天走本机 WebSocket 房间跨机器公网联机
虚拟经济商城面板与商品表、创作者署名与发布统计交易、货币、分成——一行都没写，不拿概念当功能
多端互通浏览器同源，桌面键鼠与触屏虚拟按键两套操作都可用，窄屏排版已适配原生客户端、VR

社区不是装饰

发布这件事最容易做成假的：存个标题、写死几个"别人"的名字、评论框只往 localStorage 里塞。这里的做法是服务端真的有一组账号和一组关系边，浏览器里两个隔离会话能互相看见对方做的事。

发布 = 不可变快照

点发布时，服务端把这张图的体素、脚本、实体、引用的模型与贴图整体复制一份，连同封面和元数据登记在你名下。之后你再怎么改自己那张图，别人点开玩的仍然是你发布那一刻的版本——这才谈得上"作品"。

游玩 = 把快照取回本地

详情页的「开始游玩」会取回快照、把素材落到本地资产目录、然后进运行时。跑起来的是完整引擎，不是一段视频或截图。

关系是有向的

关注是单向边，好友是双向确认：请求 → 对方接受才成边；对方先发了请求而你回一个请求，直接算接受。通知里区分"关注了你 / 想加你为好友 / 赞了你的地图 / 评论了你的地图 / 发布了新地图"。广场有最新 / 最热 / 关注三种流，"关注"流只看你关注的人和你自己。

权限是真的判过

非作者改不了、也下架不了别人的发布；路人删不掉别人的评论（地图作者可以）；未登录能读广场和评论，但写不进去；所有写操作都要带与 cookie 一致的 CSRF 头。这些不是文档承诺，test/community.test.mjs 里有 68 条断言逐条打。

创作工具

编辑器与运行时

区块按 16³ 合批，分成不透明、透明、自发光、空气墙四个网格桶；方块接缝与序列帧动画由注入的 shader 驱动，播放和切换不触发重编译。运行时是固定步长累加器，物理、区域、环境、定时器、脚本回调分段跑，每段各自捕获异常——一个子系统炸了不会把整个循环带走。

玩法脚本

按官方 GameAPI.d.ts 的成员与语义实现：World / Player / Entity / Voxels / storage，on*/next* 通道与取消语义对齐，单位是「格 / tick」而不是秒。

VOXA 建模

部件、骨骼、动画、物理盒、换肤一整套，模型能导成 .vox 与 .glb，也能被编辑器与运行时当实体资产引用。

怎么算验证过

不看编译过不过。用浏览器驱动真实页面，读像素和状态数值：按住 W 一秒走了多远、关掉模型层之后画面像素差多少、两个隔离会话互相能不能看见对方的评论。编译通过但面板宽度是 0，不算做完。

与官方的关系

引擎接口这一层是照着 dao3.fun（神奇代码岛）的公开资料做的兼容实现：参照 box3-product-document、GameAPI.d.ts 与 docs.dao3.fun，代码全部自己写，没有复制、反编译或分发任何官方源代码。目的是读得懂官方导出的地图、跑得动官方写法的脚本。

对象格式或接口情况
官方地图包.zip — code / project / build / mesh / audio导入、导出都通
Unity 侧地图.gz — gzip(JSON VoxelPayload)双向
体素模型.vox MagicaVoxel 二进制块导入、导出
模型资产.glb / .gltf，官方 mesh/*.vb 按文件名解析支持

官方平台联机、商城、云存档官方服务不接，也不打算接

示例地图里那份赛道能完整跑通：按 E 在报名点报名，人物换成汽车模型，依次过 5 个官方检查点，跑满 3 圈出成绩结算。

跑起来

要 Node 18 以上，零第三方依赖。一条命令：首次会自动构建方块图集，然后清掉本项目遗留的旧实例、挑一个空闲端口起服务。

./run.sh

起起来之后：工作台建图或复制示例模板，编辑完点世界卡片上的 ◎ 发布，社区广场就有了第一张图。换一台机器登录同名账号是没有的——账号在本机磁盘上。

PORT=8080 ./run.sh                          # 指定端口
node test/community.test.mjs                # 社区层 68 条断言
node scripts/build-block-atlas.mjs          # 改了贴图或 spec 之后重建图集
node scripts/import-official-project.mjs    # 从仓库内的官方数据重建示例地图

边界

  • 不是官方产品，和 box3lab 没有任何隶属、授权或背书关系。页面上提到官方名称，只是为了说清楚接口兼容的对象是谁。
  • 方块贴图、方块 ID 表、示例地图数据、模型和音频素材的著作权在 box3lab 和相应权利人手里。这个项目把它们放在本机，用途限于学习、技术研究和兼容性验证；确认授权前服务端不会把官方模型与音效发给前端。
  • 代码部分你可以按自己的判断用。但要把带官方素材或官方地图数据的任何东西分发出去、公开镜像、或者长得像官方产品，请先取得权利人许可。
  • 社区是本机社区：账号、发布与评论都存在这台机器上，不做公网注册、不做跨机同步，也不接任何官方平台接口。
  • 还没有做完的：虚拟经济与交易、VOXA 的拖拽 gizmo 与蒙皮权重、下水后的屏幕染色、官方体素分块的逐格比对（分块是私有二进制编码，没逆向出来）。
