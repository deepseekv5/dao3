玩

点开就跑

详情页的「开始游玩」把那份快照取回本地，跑的是完整引擎——不是视频，也不是截图。

同图联机

同一张图里的人互相能看见、能打字。走本机 WebSocket 房间，20 人上限，聊天有冷却和内容审查。

键位与触屏

桌面键鼠、手机摇杆两套都可用；屏幕按键能自己摆放，位置记在这台设备上。

会游泳

进水自动切游泳，按住空格上浮、松手缓沉，头露出来就漂平。水下按流体自己的颜色染色。

画质分档

省电到极致五档，一个按钮解决。卡了就降一档，档位是这台机器的偏好，不写进地图。

作品是快照

发布时体素、脚本、实体、模型、贴图整体复制一份。之后你再怎么改，别人玩的仍是发布那一刻的版本。

社区不是装饰

发布这件事最容易做成假的：存个标题、写死几个"别人"的名字、评论框只往 localStorage 里塞。 这里服务端真的有一组账号和一组关系边，浏览器里两个隔离会话能互相看见对方做的事。

关注是单向边，好友要双向确认。非作者改不了别人的发布；路人删不掉别人的评论； 未登录能读但写不进去。这些由 test/community.test.mjs 逐条打，不是文档承诺。

怎么算验证过

不看编译过不过。用浏览器驱动真实页面，读像素和状态数值：按住 W 一秒走了多远、 关掉模型层之后画面像素差多少、两个隔离会话互相能不能看见对方的评论。 编译通过但面板宽度是 0，不算做完。

跑起来

Node 18 以上，零第三方依赖。一条命令：首次自动构建方块图集，然后清掉旧实例、挑空闲端口起服务。

./run.sh

Windows 双击 启动-Windows.bat。不需要 npm install。

接口兼容与实现边界

引擎接口这一层是照着 dao3.fun（神奇代码岛）的公开资料做的兼容实现： 参照 box3-product-document、GameAPI.d.ts 与 docs.dao3.fun， 代码全部自己写，没有复制、反编译或分发任何官方源代码。目的是读得懂官方导出的地图、跑得动官方写法的脚本。

对象格式或接口情况
官方地图包.zip — code / project / build / mesh / audio导入、导出都通
Unity 侧地图.gz — gzip(JSON VoxelPayload)双向
体素模型.vox MagicaVoxel 二进制块导入、导出
模型资产.glb / .gltf，官方 mesh/*.vb 按文件名解析支持
玩法脚本GameAPI.d.ts 的 World / Player / Entity / Voxels对齐
方块行为block-spec 的 velocity / fluid / mass / friction / anim构建期合成
官方平台联机、商城、云存档官方服务不接，也不打算接

还没做完的：虚拟经济与交易、VOXA 的拖拽 gizmo 与蒙皮权重、官方体素分块的逐格比对（分块是私有二进制编码，没逆向出来）。
