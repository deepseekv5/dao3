游玩手册

这一页只讲怎么玩，不讲代码。要给地图写脚本的看 API 参考。

本手册按随包附带的官方「赛车模板」写：地图 ID 216d665d3ca92bd1b9a2， 3 圈、5 个检查点。其它地图的键位相同，但玩法由那张地图自己的脚本决定—— 官方脚本完全可以关掉跳跃、改掉速度或换成别的规则。

怎么开始

  • 本地包：打开工作台 →「打开赛车模板」→ 右上角「运行游戏」。或直接在浏览器进 编辑器。
  • 不想装东西：网页体验版，进页面就是运行状态，只能玩，不能编辑与存档。

进入运行模式后点一下画面会锁定鼠标用来转视角；按 Esc 解除锁定，再按一次退出运行模式。

开车时空格不是跳跃。赛车模板把玩家的跳跃力设成 0（player.jumpPower = 0）， 空格改成用来消耗加速道具。走路时按空格没反应、又提示「这张地图的脚本关掉了跳跃」，就是这个原因，不是 bug。

手机与平板

触屏设备自动出虚拟按键：左下摇杆控制方向，右下七个键—— 交互（上车/拾取）、动作 A、动作 B、飞、蹲（开车时是刹车）、 跑、跳（开车时是吃加速道具）。没锁鼠标时用按住拖动转视角。 竖屏时会提示转成横屏——竖着拿摇杆和按键会挤到赛道上。

一场比赛怎么跑

阶段你要做什么发生了什么
1 报名 走到报名点，按 E 人物被传送到发车格，换成汽车模型、人物收起；引擎声开始
2 倒计时 等着，按键此时无效 「出发倒计时：3 / 2 / 1」，这一步官方刻意锁住方向输入
3 跑圈 按顺序通过 5 个检查点，回到起点线算一圈 每个检查点通过后即被消耗；绕过去不算，必须依次经过
4 每圈结束 继续 播终点提示音，私聊里报「进度：n/3圈，用时 x 秒」
5 完赛 关掉结算框 跑满 3 圈后车停、播鼓掌声，全服播报总用时；打破纪录会单独播报，然后弹一个「用时 x 秒」的对话框

顺序错了就等于没跑。检查点只在「你的下一个」那个生效，抄近路跳过第 3 个点，第 4 个也不会认。

加速道具

  • 赛道上的道具车过碰到就拾取，身上带着时会看到提示网格发光。
  • 带着道具按 空格 才消耗：车速上限从 1.5 抬到 2.5 格/tick，同时车尾喷粒子。
  • 加速有时长，到点车速与外观都自动恢复。
  • 被吃掉的道具大约 3 秒后回到原位，下一辆车还能再吃。
攒着不放等于没有。直道末端吃、弯前放开，比一直按着 Shift 快得多。

悬浮操作按钮

这套屏幕按键不是手机专属。按 H 打开设置面板，点悬浮按键就能在任何设备上 把它们浮在画面上——包括用鼠标点（桌面默认关着，免得挡视野）。

  • 按键是悬浮层：只有按钮本身接点击，中间那块区域是透的，照常锁定视角、照常点世界里的东西。
  • 点摆放按键进入摆放模式，把摇杆底盘和按键组拖到顺手的位置，再点完成摆放。 摆放模式下按下不会真的触发操作，可以放心拖。
  • 位置记在这台设备上（浏览器本地存储），换地图、重开应用都还在；点复位回到默认布局。
  • 退出运行模式后悬浮层自动收起，不会留在编辑器界面上。
开关与摆放属于操作习惯，不属于地图数据——所以它不会被存进 .json.gz， 也不会跟着项目包发给别人。

掉出世界、卡住与重生

坐标掉到世界之外会自动重生回出生点。要是卡在建筑里出不来，按 Esc 退出运行模式再进一次；H 打开的设置面板里有立即重生按钮。写脚本的人可以直接调 player.forceRespawn()。

常见问题

按空格没反应
两种情况：开车时空格是消耗加速道具；走路时如果屏幕提示「这张地图的脚本关掉了跳跃」，说明这张图把 jumpPower 设为 0，是地图设计而不是故障。
上车之后屏幕被车壳糊住、什么都看不见
1.0.7 之前是真 bug（跟随相机被车身自己挡住，压到了贴身距离），现在已修。如果你还看到这个现象，先确认用的是最新包。
车子前进但轮子不转
官方赛车模型的动画轨道在 .vb → glTF 的转换里没有保留，源动画文件不在这批公开素材里，所以轮子确实不会转。运行时会明确提示「该模型不含任何动画数据」而不是静默假装播放。这是素材缺口，不是逻辑没写。
鼠标转不动视角
没锁定成功（按过 Esc、或在 iframe 里）。按住左键拖可以转视角；点一下画面重新请求锁定。
手机上进面就卡、找不到按键
确认浏览器允许全屏并横屏；虚拟按键在横屏下才摆得开。体验版在竖屏会提示你转过去。
我的改动会上传吗
不会。编辑数据全部存在你这台机器的 server/data/worlds/ 下，服务端不外连。网页体验版是只读镜像，退出即无。

想自己改玩法

键位、速度、能不能跳、几圈结束，全都是地图脚本里 player.* 与 world.* 的事。 从编辑器右上角「脚本」页开始改，接口查 API 参考 （逐个成员的签名、单位与中文说明），单位与物理的口径看 物理与单位制。
