游玩手册

只讲怎么玩。写脚本看 API 参考。

键位是所有地图共用的；玩法不是。能不能跳、能开多快、有没有车、算不算赢， 都由那张图自己的脚本决定。下面写「需地图开启」的地方，都是作者可以关掉的。

怎么开始

  • 本地包：工作台里任选一张图 → 右上角运行游戏。
  • 社区：广场上的图点游玩即可，是作者发布那一刻的快照。
  • 不想装东西：网页体验版，只能玩。

进运行模式后点一下画面锁定鼠标转视角。Esc 先解锁，再按一次开游戏内菜单—— 菜单浮在画面上，世界继续跑，出口在菜单里。

水里

游进水面就会自动切到游泳：移动变慢、会缓沉。按住空格上浮，松手缓沉， 头露出水面就自己漂平——和 Minecraft 一样。

镜头进水里画面会染上那种流体自己的颜色，可视距离同时收短。 水不是实心，踩不到底，落到池底再按空格往上走。

触屏

触屏设备自动出虚拟按键：左下摇杆，右下交互 / 动作 / 飞 / 蹲 / 跑 / 跳。 桌面也可以开——设置面板里点悬浮按键。

  • 摆放按键把摇杆和按键拖到顺手的位置，再点完成摆放；复位回默认。
  • 位置记在这台设备上，不写进地图数据，也不会跟着项目包发给别人。
  • 竖屏建议转横屏，竖着摇杆和按键会挤在一起。

卡住与重生

掉出世界会自动回出生点。卡在建筑里就按 H 点立即重生； 实在不行 Esc 退出再进。

常见问题

按空格跳不起来
这张图的脚本把 jumpPower 设成了 0，是地图设计。水里按空格是上浮，不是跳。
鼠标转不动视角
没锁定成功。按住左右键拖动也能转；点一下画面重新请求锁定。
画面卡
右上角画质降一档。像素比和阴影是最吃性能的两项。
我的改动会上传吗
不会。全部存在你这台机器的 server/data/ 下，服务端不外连。

想自己改玩法

键位、速度、能不能跳、怎么算赢，都是地图脚本里 player.* 与 world.* 的事。 编辑器右上角「脚本」页开始改，接口查 API 参考， 单位口径看 物理与单位制。
