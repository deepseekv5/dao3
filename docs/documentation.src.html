怎么访问这批文档

  • 线上：GitHub Pages 上本页地址为 deepseekv5.github.io/dao3/documentation.html，每篇正文是同目录下的 *.html。
  • 本地跑起服务时：./run.sh（或 node start.mjs）会打印实际端口，后面接 /docs/documentation.html 就是本页；默认端口 5173，被占用时自动顺延。
  • 在仓库里：直接读 docs/*.md，GitHub 网页也能渲染；生成物 docs/*.html 只为 Pages 与本地站点服务。
  • 重建：npm run build:docs（等价 node scripts/build-docs.mjs），幂等，无需联网、无需装包。

介绍站首页（./）是营销式概览：实拍截图、数字、能力矩阵、下载与授权边界，其中也带一份同一批文档的卡片清单； 需要成体系地读，就从本页进。
